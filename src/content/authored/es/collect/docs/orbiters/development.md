# <span class="mark mark--cut mark--tilt-3 mark--tear-2">Desarrollo</span>

Por ahora estamos desarrollando dos versiones de los Orbiters: una versión web y una aplicación de escritorio para Mac y Windows, pensada para tocar en vivo y en línea.

![Imagen](/img/docs/orbiters/03_int-development.png "Desarrollo del reproductor web")

## Versión web hecha con p5.js y RNBO, publicada bajo la licencia GPL-3.0.
El proyecto es de código abierto y está al alcance de cualquiera que quiera experimentar con el código: una herramienta potente para quien busque correr los límites de la creación y la escucha musical.

![Imagen](/img/docs/orbiters/02_web-player.png "Desarrollo del reproductor web")

<a href="https://p5js.org" target="_blank">p5.js</a> es una biblioteca de JavaScript con un conjunto de herramientas para crear gráficos interactivos, animación y sonido en el navegador. Está pensada para ser amable y accesible, lo que la volvió una opción popular tanto para quien empieza como para quien tiene experiencia. Con p5.js se pueden crear experiencias visuales y sonoras complejas con una sintaxis simple e intuitiva.

<a href="https://rnbo.cycling74.com" target="_blank">RNBO</a>  es una biblioteca y una cadena de herramientas para construir y exportar software que incorpora el sonido de Max, un lenguaje de programación visual muy usado en música y multimedia. Con RNBO se puede crear una gama amplia de proyectos musicales —experiencias web, dispositivos de hardware, plugins de audio y objetos nuevos de Max— todo desde el mismo patch.
Además, RNBO ofrece una interfaz intuitiva y amable para parchear y experimentar con código, lo que la hace accesible a mucha gente distinta. En conjunto, RNBO es una herramienta nueva y entusiasmante tanto para músicas y músicos como para quienes programan: una plataforma potente y versátil para crear y experimentar con música.

## Versión de escritorio.
La versión de escritorio es un prototipo que puede estar disponible a pedido.
