# Migration ledger

Append-only record of completed units of work for the Maar World rebuild (Linear epic MW-1).

**This file is a record, not a working file.** Never rewrite it. Never reorder it. Never
delete a line. Only append. `npm run ledger:check` fails if the committed version stops
being a prefix of the working copy.

The first action of any agent session is to read this file. The last action before stopping
is to append to it.

## Line format

```
<stamp>            <issue>  <status>  <unit>                                     <detail>
2026-07-29T02:14Z  MW-7     DONE      lab/en/ip-1.html                           routes:ok content:ok links:ok
2026-07-29T02:16Z  MW-7     BLOCKED   lab/es/dadada.html                         reason: source references missing image
```

Machine-parseable as `^(stamp)\s+(MW-\d+)\s+(DONE|BLOCKED|NOTE)\s+(unit)\s+(detail)$`.

| Field | Rule |
|---|---|
| `stamp` | UTC, minute precision, `YYYY-MM-DDTHH:MMZ` |
| `issue` | Linear issue key, `MW-<n>` |
| `status` | `DONE`, `BLOCKED` or `NOTE` — nothing else |
| `unit` | one token, no spaces: a route, file path, or named checkpoint |
| `detail` | free text; **required** for `BLOCKED`, and must state the reason |

Padding is cosmetic. Parsing splits on whitespace runs, so alignment can drift without
breaking anything.

Append with the CLI rather than by hand — it stamps the time and rejects malformed entries:

```
npm run ledger -- append MW-7 DONE lab/en/ip-1.html "routes:ok content:ok links:ok"
npm run ledger -- append MW-7 BLOCKED lab/es/dadada.html "reason: source references missing image"
```

(3) FONT-STRETCH IS CURRENTLY UNREPRODUCIBLE, ALSO NOT PREVIOUSLY NAMED. 4a sets font-stretch 110-124% on every Archivo mark and it is part of why a cut word reads as a clipping and not a chip. the installed dependency is @fontsource/archivo, which ships static weight files with NO width axis - checked, no wdth and no font-variation-settings in the css - so font-stretch would silently do nothing. it is therefore NOT in mark.css: a declaration that cannot take effect is worse than an absent one, because the next session reads it as done. getting it needs @fontsource-variable/archivo (wdth 62-125), which is a dependency swap affecting every Archivo glyph on the site - h2, h3, buttons, chips - not just the marks. that is the owner's call and it is the single change that would most narrow the gap to 4a. (4) OFF-PALETTE COLOUR. nothing off-palette shipped. 4a's structural near-misses collapsed onto tokens as recommended: its #141319 mark ink is --c-dark #100f14, and its #efe7da cream field is --sf-paper, which is the same value already. none of 4a's neon (#ff3ec8, #35e8e0, #ffb340) is used. (5) A ONE-WORD HEADING BECOMES AN ALL-OVER FIELD. /lab's h1 is the single word 'lab', so mark.highlight paints the entire heading and it reads closer to a badge than to a marked word - visible in the screenshot for this unit. the spec permits it ('one per heading', no minimum length) and 4a never shows the case because none of its headings is one word. cheapest fixes if the owner dislikes it: prefer the cut word when a heading has only one eligible token, or skip the mark entirely below two tokens. one condition in src/lib/mark.mjs either way
